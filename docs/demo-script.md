# 3–5 分钟答辩演示

版本：v2.0

建议固定使用随机种子 `104729`、参考长度 `3200`。

1. 打开程序，指出工作台没有预置结果，三个输入路径分别是生成、文件夹导入和分别选择文件。
2. 选择保存父目录，输入种子并点击“生成并加载”。展示实际数据集目录、3,200 bp 参考序列、50 条 50–150 bp Reads 和真值文件。
3. 进入“索引状态”，说明连续 `bytearray`、K-mer 冲突链与位置链是两层不同的手写链表。重点展示窗口数等于位置节点数 `N-K+1`，以及真实最长桶链。
4. 回到工作台，以 K=6、阈值 2、开启剪枝运行。命中数量由本次随机种子的 0-2 错配 Read 数量决定，不再固定为 30/50；被拒绝但错配不超过 3 的 Read 会在坐标图和对比沙盘中以红色显示。
5. 在全基因组坐标图中点击任一命中，展示 Read、参考位置、种子桶、候选数、比较字符数、剪枝数及黄色错配碱基。
6. 打开 Reads 列表，使用“未命中”筛选选择一条 3 错配 Read，回到工作台说明当前阈值为什么拒绝。
7. 将阈值改为 3 再运行，展示所有生成 Read 均可找回真实来源，且命中集合不会随阈值增大而减少。
8. 打开报告页说明错配分布、候选缩减和真实耗时，导出 `run_report.json` 与 `reads_results.csv`，或打开系统打印预览。

需要主动说明的边界：只处理替换型错配；不处理插入、删除、反向互补链、SAM/BAM 和真实测序质量模型；外部 Reads 若前 K 位本身含错配，精确种子可能造成假阴性。
